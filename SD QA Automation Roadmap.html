🚦 Rule for new development in 2027
  • Every new API operation or page on a development branch gets QMetry cases and an automated test in the same sprint, plus a DB check wherever it writes data. This keeps the backlog from growing while the plan clears it.

📋 Assumptions
  • Capacity: same team size as 2026 (≈50 new nightly tests a month)
  • Not automatable: PMS integrations, camera/hardware, sensors, 2FA/OTP/CAPTCHA, SMS delivery, visual-only, device telemetry
  • Nightly tests vs cases: one case can be several nightly tests; the 2027 plan counts QMetry cases
  • API coverage counts direct API tests only, not calls the browser makes during UI tests
  • Plan % uses today's 1,750 automatable cases; new 2027 cases follow the same-sprint rule
